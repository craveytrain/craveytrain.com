Foundations

Color

main.css :root

Two layers. The palette (Layer 1) is fourteen fixed pigments, identical in jour and nuit, and never referenced by a component rule. Semantic roles (Layer 2) are what components actually use; flipping jour ↔ nuit is only ever a re-point of a role at a different pigment. There is no third, component-level token tier. Every text/ground pair is validated numerically by scripts/wcag.py, not by eye.

Typography

Bebas Neue · Jost · Yellowtail

Uppercase is wayfinding, not decoration. Bebas display caps mark titles, band headings, year numerals, and date stamps. Jost caps with wide letter-spacing carry structural voice, nav, tag links, buttons, footer. Jost normal case is running prose; prose never shouts. Yellowtail is a flourish only, never body copy, never navigation, always rotated −2° to −3°, never more than one per view section.

Poster frame

body (main.css)

The page is the poster: a 14px --frame border (8px below 768px) with a 2px keyline inset, applied to body, page-level only, never nested on an inner element. It's not a demo prop on this page: it's the actual rule wrapping this very document right now, because main.css sets it on the bare body selector with no page-class scoping. Look at the edge of your browser window.

Theme toggle

static/js/theme-toggle.js · <theme-toggle>

Three states, cycled by clicking: jour (forced light), nuit (forced dark), auto (follows the OS, the default). A vanilla custom element, no shadow DOM, so it inherits the site's global styles, styled in main.css exactly in the nav-link voice. The choice persists to localStorage under the key theme (absent means auto) and sets data-theme on <html>, which forces color-scheme so every light-dark() role resolves to the pinned mode. Each change also syncs both meta[name=theme-color] tags for Safari chrome tinting. With JavaScript disabled the element never upgrades and renders nothing, the site falls back to pure OS preference (auto).

Tag links

.tag-links (main.css) vs .row-tags (posts.css)

Two separators, two voices, never mixed in one list. Emphatic accent caps use a gold ◆ (a literal <span>◆</span>, not a border or pseudo-element); quiet inline tag rows use a muted middot. Tags never wrap: four or more truncate to three plus a muted, non-link +N.
